# X3 UAV

Gazebo Fuel **X3 UAV**, version 4, published by Open Robotics. The model metadata credits Carlos Aguero and Cole Biesemeyer. The model and meshes are redistributed under Creative Commons Attribution 4.0 International. [Gazebo Fuel catalog](https://fuel.gazebosim.org/1.0/OpenRobotics/models/X3%20UAV) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The simulation script uses these assets to generate colored pursuer and target models and attaches a camera and contact sensors at runtime.
